# About this fork

This fork tracks [dip/cmdk](https://github.com/dip/cmdk). Upstream has not merged a pull request since August 2025 ([#372](https://github.com/dip/cmdk/pull/372)), and newer pull requests are unreviewed. This fork's `main` is upstream `main` plus the pull requests below.

Each pull request is merged with its original commits and authors. A change made on top of a pull request is a separate commit, with its author as co-author.
